# 侧边栏扩展 · 安装说明

Chrome / Edge 原生 `sidePanel`。点一下图标，右侧栏就是侧车，宽度可以拖到 400–480px。
它**只打开一个本地 URL**，不注入脚本、不读你正在看的网页、不看历史记录。

---

## 0. 先决条件

1. 侧车服务得在跑：

   ```
   双击项目根目录的 启动.bat
   ```

   或者手动：

   ```
   cd D:\新建文件夹\2026-11-08-18-46-10
   python -m streamlit run app.py
   ```

2. 浏览器版本：**Chrome 114+ / Edge 114+**。
   116+ 才能做到"点图标直接开"；114–115 需要点图标后在侧栏下拉里选一次本扩展。

先确认 `http://localhost:8501` 能打开，再装扩展。装完发现"没有服务"，八成是这一步没做。

---

## 1. 安装（Chrome）

1. 地址栏进 `chrome://extensions`
2. 右上角打开 **开发者模式**
3. 点 **加载已解压的扩展程序**
4. 选中这个文件夹：`D:\新建文件夹\2026-11-08-18-46-10\sidepanel-extension`
   （选文件夹本身，不是里面的某个文件）
5. 列表里出现「认知掌控侧车 · 侧边栏」→ 点拼图图标把它 **固定** 到工具栏

## 1'. 安装（Edge）

步骤一样，地址换成 `edge://extensions`，左下角打开「开发人员模式」，
然后「加载解压缩的扩展」→ 选同一个文件夹。

---

## 2. 用

点工具栏上的图标 → 浏览器右侧打开侧栏 → 自动进 `?embed=true&narrow=1`。

- 宽度：把侧栏左边缘往左拖，**400–480px** 是这版 UI 的设计区间（320px 也还能用，只是标题会折行）。
- 想切页面：侧栏顶部那排选项卡（工作台 / 结果卡 / 规则库 / 设置），不需要侧边栏。
- 想回到宽屏：直接开 `http://localhost:8501/` 就是原来的样子，两种形态共用一个进程、一个数据库。

### 侧栏打开时会自动接上最近一次会话

侧栏每次打开都是新页面，`session_id` 一定是空的。所以窄栏下会默认挂到**最近一条会话**上
（不是新建）——"接着上次看"几乎总是本意。想开新的，顶上会话下拉里选「＋ 新建会话」。

---

## 3. 出问题怎么查

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 面板显示「localhost:8501 上没有服务」 | 服务没起，或端口不是 8501 | 先跑 `启动.bat`；端口不同就在面板底部改端口再点「重试」 |
| 点图标没反应 | 浏览器低于 114，或扩展没固定 | `chrome://extensions` 里看有没有报错；114–115 用侧栏下拉手动选一次 |
| 侧栏一片空白 | Streamlit 还没编译完 | 等 2–3 秒；仍空白就点面板上的「重试」 |
| 面板里是宽屏样式 | URL 少了 `narrow=1` | 面板地址应是 `http://localhost:8501/?embed=true&narrow=1` |
| 改了 `manifest.json` 不生效 | 扩展没重载 | `chrome://extensions` 里点该扩展的刷新按钮 |

调试：`chrome://extensions` → 该扩展 → 「Service Worker」/「检查视图」可以看 console。

---

## 4. 它到底拿了你什么

```json
"permissions": ["sidePanel", "storage"],
"host_permissions": ["http://localhost/*", "http://127.0.0.1/*"]
```

- `sidePanel`：只用来自 `chrome.sidePanel.open()` 和 `setPanelBehavior`。
- `storage`：只存一个数字——端口号。
- `host_permissions`：只对 localhost 生效，用来在面板里探一下 `/_stcore/health`；
  **没有** `<all_urls>`，所以它连你访问的网站域名都碰不到。
- 没有 `content_scripts`、没有 `tabs`、没有 `history`、没有 `scripting`。

想卸载：`chrome://extensions` → 移除。侧车本体和数据库完全不受影响。

---

## 5. 文件都是干什么的

```
sidepanel-extension/
  manifest.json    MV3 声明：side_panel 指向 panel.html，权限只有 sidePanel + storage
  background.js    图标点击 → 打开侧栏；没有 sidePanel 的浏览器退化成独立小窗口
  panel.html       面板首屏：一句状态 + 重试 + 端口
  panel.js         探活（no-cors fetch /_stcore/health）→ 通了就 location.replace 进应用
  icons/           16/32/48/128
```

为什么面板是"先探活再整页导航"，而不是 `iframe` 嵌进去：

1. Streamlit 会带 `X-Frame-Options` / `frame-ancestors`，iframe 大概率直接白屏；
2. iframe 里的滚动、输入焦点、`100vh` 计算都会差一截；
3. 整页导航之后，侧栏里就是那个页面本身——CSS 断点、键盘、粘贴都是原生的。

代价是：一旦导航进应用，面板首屏就不在了。所以探活必须发生在导航**之前**，
否则你会对着一个浏览器的"无法访问此网站"发呆。
